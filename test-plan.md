# Manual Test Plan — SauceDemo

**Application under test** — [SauceDemo](https://www.saucedemo.com/)

## Objective

Verify that a shopper can sign in, manage the cart, and complete checkout.

## Test Scope

- **Login** — Check valid credentials, invalid credentials, and empty required fields.
- **Cart** — Add and remove products, then verify the cart contents.
- **Checkout** — Check required field validation and verify that a completed order displays a confirmation.

## Test Approach

Run each scenario manually in a desktop browser. Record the expected result, actual result, and test status.
