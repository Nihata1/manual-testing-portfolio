# SauceDemo Manual Testing Portfolio

I designed and executed seven manual functional tests for the [SauceDemo](https://www.saucedemo.com/) demo store.

## Test Coverage

- **Login** — Valid credentials, invalid password, and empty username validation
- **Cart** — Adding a product and removing the last item
- **Checkout** — Order confirmation and required postal code validation

## Test Results

**7 executed · 7 passed · 0 failed**
