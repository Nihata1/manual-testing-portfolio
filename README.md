# Manual Testing Portfolio

## GreenLeaf Grocers — Checkout Case Study

This QA training project covers manual test design and defect reporting for an online grocery checkout.

### Test Scope

- **Guest checkout** — Check that a guest can place an order and see an order ID on the confirmation page.
- **Form validation** — Check that leaving a required field blank prevents order submission and displays a validation message.
- **Promo codes** — Check how checkout handles expired codes and whether the promo code field is usable on mobile.
