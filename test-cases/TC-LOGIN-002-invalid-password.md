# TC-LOGIN-002 — Login with an Invalid Password

## Preconditions

- The user is signed out.
- The [SauceDemo login page](https://www.saucedemo.com/) is open.

## Test Data

| Field | Value |
|---|---|
| Username | `standard_user` |
| Password | `invalid_password` |

## Test Steps

1. Enter the username and invalid password from the test data.
2. Click **Login**.

## Expected Result

The application rejects the login attempt and displays an invalid credentials message on the login page.
